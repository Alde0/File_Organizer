# File Organizer
A simple file sort utility
## Sorting Structure
- `Images` — `.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`
- `Videos` — `.mp4`, `.mkv`, `.mov`, `.avi`
- `Documents` — `.docx`, `.pdf`, `.txt`, `.rtf`, `.csv`, `.pptx`
- `Musics` — `.mp3`, `.flac`, `.aiff`, `.ogg`
- `Archives` — `.zip`, `.7z`, `.rar`, `.tar`, `.gz`
- `Other` — other files
